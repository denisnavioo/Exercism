# Exercism - Java

Este repositorio reúne mis soluciones a ejercicios de [Exercism](https://exercism.org/), una plataforma para practicar programación mediante ejercicios y aprender distintos lenguajes.

## ¿Por qué Java?

He elegido Java porque es el lenguaje que estoy aprendiendo en clase y en el que quiero seguir profundizando. Resolver estos ejercicios me permite practicar los conceptos poco a poco y aplicar lo que voy aprendiendo.

## Ejercicios

Las soluciones están organizadas por lenguaje y ejercicio:

```text
solutions/
└── java/
    ├── annalyns-infiltration/
    ├── bird-watcher/
    ├── hello-world/
    ├── karls-languages/
    └── lasagna/
```

Cada carpeta contiene la solución correspondiente al ejercicio de Java.

## ¿A quién puede servir?

Este repositorio puede servir como referencia para otras personas que estén empezando con Java y quieran ver ejemplos de soluciones a ejercicios de Exercism. Las soluciones reflejan mi proceso de aprendizaje, así que puede haber distintas formas de resolver un mismo ejercicio.

## Sobre Exercism

[Exercism](https://exercism.org/) permite practicar programación con ejercicios de diferentes lenguajes y niveles. Puedes consultar la plataforma y probar los ejercicios por tu cuenta.
